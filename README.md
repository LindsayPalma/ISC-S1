**1 Hardware**

Es el conjunto de los componentes físicos y tangibles que integran una computadora o sistema informático. Se refiere a todo aquello que puedes tocar: desde los circuitos internos como el procesador y la memoria RAM hasta los periféricos externos. Sin el hardware, el software no tendría un lugar donde ejecutarse.

**2 Software**

Es el soporte lógico e inmaterial que permite que el hardware realice tareas específicas. Se compone de un conjunto de instrucciones, programas, reglas y documentación que indican a la máquina qué hacer. Se divide generalmente en software de sistema, software de aplicación y herramientas de desarrollo.

**3 Firmware**

Es una categoría específica de software que tiene como propósito controlar directamente el hardware de un dispositivo. Se almacena en memorias no volátiles y actúa como el puente de comunicación más bajo entre el hardware físico y el sistema operativo. A diferencia del software común, el firmware no suele ser modificado por el usuario final y es crítico para el arranque del equipo.

**4 BIOS / UEFI**

Es el primer programa que se ejecuta al encender una computadora.
 * BIOS (Basic Input/Output System): El estándar antiguo que inicializa el hardware y busca el sistema operativo.
 * UEFI (Unified Extensible Firmware Interface): La versión moderna y mejorada de la BIOS, que soporta discos más grandes, tiempos de arranque más rápidos, interfaces gráficas y mayores niveles de seguridad.
   
**5 Datos**

En informática, los datos son representaciones simbólicas de un atributo o variable. Por sí solos no tienen sentido, pero una vez procesados, se convierten en información útil. Son la materia prima de cualquier sistema computacional.

**6 Base de Datos**

Es un almacén de datos estructurado de forma sistemática para que se pueda recuperar, gestionar y actualizar fácilmente. No es solo un "archivo", sino un sistema que permite relacionar grandes volúmenes de información de manera eficiente.
Conectividad y Redes

**7 Redes**

Es un conjunto de nodos interconectados entre sí mediante medios físicos o inalámbricos para compartir recursos, archivos y servicios. Las redes permiten la comunicación global, siendo Internet la "red de redes" más grande que existe.

**8 APIs (Application Programming Interfaces)**

Una API es un conjunto de reglas y protocolos que permite que dos aplicaciones de software se comuniquen entre sí. Actúa como un intermediario: si una aplicación de clima quiere mostrar datos en tu teléfono, usa una API para "pedirle" esa información al servidor meteorológico sin necesidad de saber cómo funciona internamente ese servidor.

**9 IoT (Internet of Things)**

El Internet de las Cosas se refiere a la red de objetos físicos que llevan incorporados sensores, software y otras tecnologías con el fin de conectar e intercambiar datos con otros dispositivos y sistemas a través de Internet. Ejemplos comunes son las bombillas inteligentes, termostatos y sensores industriales.

**10 Sistema Embebido**

Es un sistema de computación diseñado para realizar una o pocas funciones dedicadas dentro de un sistema mecánico o eléctrico más grande. A diferencia de una PC de propósito general, un sistema embebido está optimizado para una tarea específica como el controlador de una lavadora, el sistema de frenos de un auto o un reloj digital.

**11 Microcontroladores**

Es un circuito integrado programable que contiene todos los componentes de una computadora en un solo chip: CPU, memoria y periféricos de entrada/salida. Es el "cerebro" detrás de la mayoría de los sistemas embebidos y del IoT, diseñado para controlar dispositivos electrónicos con bajo consumo de energía.

**12 Nube**

Es la entrega de servicios de computación servidores, almacenamiento, bases de datos, redes a través de Internet. En lugar de tener un servidor físico en tu oficina, alquilas potencia de cómputo de proveedores como AWS, Google Cloud o Azure, pagando solo por lo que usas.

**13 Docker (Contenedores)**

Es una plataforma de código abierto que permite empaquetar una aplicación con todas sus dependencias en un "contenedor". Esto garantiza que la aplicación funcione exactamente igual en la computadora del desarrollador, en un servidor de pruebas o en la nube, eliminando el problema de "en mi máquina sí funciona".

**14 Cloud Engineer**

Es el profesional responsable de diseñar, implementar y gestionar la infraestructura en la nube. Se asegura de que los sistemas sean escalables, seguros y rentables.
Desarrollador de Software
Es el especialista encargado de crear, diseñar y mantener aplicaciones y sistemas. Utiliza lenguajes de programación para traducir necesidades humanas en código que la computadora pueda ejecutar. Su rol abarca desde la lógica del negocio hasta la interfaz que ve el usuario.

**15 DevOps**
Más que un puesto, es una metodología o cultura de trabajo que combina el Desarrollo (Dev) y las Operaciones (Ops). Su objetivo es acortar el ciclo de vida del desarrollo de software, permitiendo que las actualizaciones se publiquen de forma frecuente, automática y con la menor cantidad de errores posible.
