# ISC-S1

Glosario

**1 Hardware**

Se refiere a la arquitectura física y los componentes materiales que constituyen un sistema informático. Es todo aquello que se puede tocar. Se divide generalmente en hardware de procesamiento, de almacenamiento , periféricos de entrada, de salida y hardware de red. Sin el hardware, el software no tendría un lugar donde ejecutarse, funcionando como el "cuerpo" de la máquina.

**2 Software**

Es el soporte lógico e inmaterial que permite que el hardware realice tareas específicas. Consiste en un conjunto de programas, procedimientos, reglas y documentación que instruyen a la computadora sobre qué hacer. El software se clasifica habitualmente en tres tipos: de sistema, de aplicación y de programación herramientas para crear otros programas.

**3 Sistemas**

En informática, un sistema es un conjunto complejo de elementos interrelacionados (hardware, software, datos y usuarios) que trabajan de manera coordinada para procesar información. Un sistema sigue un ciclo de vida: recibe una entrada, realiza un proceso y genera una salida. Es una estructura organizada que busca resolver un problema o cumplir una función específica.


**4 Entradas**
Son los datos o señales captados por el sistema desde el mundo exterior para ser procesados. La entrada puede provenir de un usuario humano, de otro sistema o de sensores ambientales. Es el combustible de la informática; sin datos de entrada, el sistema no tiene materia prima sobre la cual operar.

**5 Salidas**

Es el resultado final del procesamiento de los datos. La salida es la información útil que el sistema devuelve al usuario o a otro dispositivo. Puede manifestarse de muchas formas: texto en una pantalla, sonido por los altavoces, un documento impreso o incluso una señal que activa un motor en una fábrica.

**6 Almacenamiento**

Se define como la capacidad del sistema para retener información de manera que pueda ser recuperada posteriormente. Se divide en almacenamiento primario, que es volátil y rápido para procesos actuales, y almacenamiento secundario, que es permanente y guarda tus archivos, fotos y el propio sistema operativo aunque se apague la energía.

**7 Procesos**

Un proceso es una instancia de un programa en ejecución. Implica una serie de pasos u operaciones lógicas que la Unidad Central de Procesamiento realiza sobre los datos de entrada. Durante un proceso, el sistema organiza, calcula, compara y transforma los datos brutos en información con significado, utilizando los recursos del sistema de forma eficiente.

**8 Nube**

Es un modelo tecnológico que permite el acceso a servicios de computación (servidores, almacenamiento, bases de datos, redes) a través de Internet. En lugar de depender de un disco duro local o un servidor físico en casa, la "nube" permite que los datos se ubiquen en centros de datos remotos en todo el mundo, ofreciendo movilidad, escalabilidad y ahorro de costos.

**9 Servidores**

Son computadoras de alto rendimiento diseñadas para atender las peticiones de otras computadoras dentro de una red. Un servidor puede alojar sitios web, gestionar correos electrónicos o almacenar bases de datos empresariales. Su característica principal es que suelen estar encendidos las 24 horas del día para garantizar que la información esté siempre disponible.

**10 Datos**

Los datos son la unidad mínima de información, representaciones simbólicas (números, letras, hechos) que por sí solas no tienen un sentido completo. Solo cuando los datos son procesados, agrupados y contextualizados por un sistema, se convierten en "información" útil para la toma de decisiones.

**11 Usuario**

Es el sujeto humano que utiliza, interactúa o se beneficia de un sistema informático. El usuario es el centro del diseño tecnológico (Experiencia de Usuario o UX), y sus necesidades dictan cómo se desarrollan las aplicaciones y dispositivos. Puede ser un usuario final que solo usa la app o un administrador que gestiona el sistema.

**12 Sistema operativo**

Es el software fundamental y más importante de una computadora. Actúa como el intermediario principal entre el usuario y el hardware. Sus funciones incluyen la gestión de la memoria, la administración de archivos, el control de periféricos y la ejecución de aplicaciones. Ejemplos clásicos son Windows, Linux, macOS o Android.
